# ADR 001 — in-process whisper.cpp and native window

Status: implemented; initial measurement recorded in PERFORMANCE.md.

Choose whisper-rs 0.16 (vendored whisper.cpp) in-process, with Metal on aarch64 macOS. The stable binding bundles native sources, avoids a separate server/runtime/sidecar protocol, and lets one context remain warm across sessions. A sidecar would improve inference-crash isolation but add build/signing/process lifecycle work. Revisit if measurements or native crashes show in-process isolation inadequate. No HTTP server, Python or Docker is used.

The spike exercises actual model load and repeated inference via the same production adapter. The first run exposed an upstream safe abort-callback issue; the production adapter uses a documented synchronous raw callback with bounded userdata lifetime. Measurements must identify the backend rather than infer acceleration from compile flags.

Keep Rubato 0.16.2 for its fixed-input sinc API, with synthetic duration/anti-alias tests; the current major has a redesigned API. Other principal dependencies were verified through npm, Cargo and official Tauri/Whisper docs and exact resolutions are locked in package-lock.json/Cargo.lock. React 19.3, Vite 8.3, Tauri 2.12, CPAL 0.18 and SQLite/rusqlite 0.40 were resolved on this host.

Use a persistent Tauri WebviewWindow (`decorations=false`, `focusable=false`, `focus=false`, `alwaysOnTop=true`, initially hidden). Public NSWindow collection behaviors support all Spaces/fullscreen auxiliary display. Transparency is omitted to avoid Tauri's macOS private API feature; the overlay uses an opaque rounded surface. NSPanel is deferred until actual Spaces/focus testing demonstrates the need. It is not claimed equivalent to a fully tested NSPanel.

Native AX selected-text insertion avoids synthesized paste keystrokes and automatic clipboard changes. Unsupported controls degrade to explicit Copy. VAD is a documented configurable energy gate, not a neural speech detector. Optional history is plaintext SQLite protected by OS storage/account security; introducing encryption requires Keychain-managed keys and a migration, not a hardcoded secret.
